# R-Shop 1.9.0

- Flat physical-media previews are the default, with handwritten labels when artwork is missing.
- Import your original Socket Launcher 0.7 APK in Settings → Display → Media previews to unlock local 3D cartridge and disc models. Then enable 3D explicitly.
- Resolved box art appears in front of the media, slides left and reveals the cartridge as it smoothly grows to its normal size. Works in flat and 3D modes.
- Missing or loading artwork and reduced motion skip the reveal.
- Imported resources survive app restarts. Cancelled or rejected imports preserve the last valid import and leave the original APK unchanged.

The published APK contains no extracted Socket assets or engine. Import runs locally, without uploading or installing the source APK. This importer supports the original 0.7 APK, not arbitrary versions or repackaged copies.

Updates retain package `com.darkaxt.rshop`, the existing signing identity and the standard `app-release.apk` filename. Existing accounts, library settings, ROMs and saves are preserved. ScreenScraper refresh remains a user action.
