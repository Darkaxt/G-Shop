# R-Shop 1.8.0

First production release of this fork, using package `com.darkaxt.rshop` and the
standard `app-release.apk` filename. Android 7.0 or later; ARM64 Flutter runtime.

- Browse Google Drive game collections and download games on demand.
- Fresh game metadata, service ratings, dynamic Top filters and variant tags.
- Shared metadata/artwork storage, ES-DE integration and console dashboards.
- Configurable game cache retention and rotation.
- Root-assisted save/companion-data backup with offline queues and conflict handling.
- Per-game companion apps and a red-themed physical-media presentation.

Provider credentials are configured on your device and are not bundled in the APK.
Google sign-in requires an OAuth registration matching this release's package and
signing certificate. ScreenScraper collection refresh remains a user action.

This package is distinct from the development app. Migrate reusable settings and
data before uninstalling the development package; its encrypted sign-in tokens
cannot be transferred to the production package. Future releases reuse the same
production signing identity so ObtainX/Obtainium can update the app in place.
