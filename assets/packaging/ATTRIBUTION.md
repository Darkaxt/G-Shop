# Cardboard geometry

Adapted from [Diskette box](https://sketchfab.com/3d-models/diskette-box-c179241faa984442a9a802d867bc60f5)
by [matousekfoto](https://sketchfab.com/matousekfoto), licensed under
[Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).

Changes: original mesh reoriented and normalized for independently parameterized
width, height and depth; six planar UV regions replace the original floppy-disk
artwork; original textures removed; matte non-metallic material. This does not
claim to reproduce an original Nintendo retail box's exact wear.

The conversion script and source digest are retained in the repository. No game
artwork or proprietary manual resources are included in these public assets.
